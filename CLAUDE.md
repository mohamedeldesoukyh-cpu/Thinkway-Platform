# Thinkway Engineering Rules

## Stack

- Next.js App Router

- TypeScript

- Tailwind CSS

- shadcn/ui

- Supabase

- Vercel

## Rules

- Strict TypeScript

- Mobile responsive

- Reusable components only

- No duplicated logic

- Modular architecture

- Use server actions when possible

- Keep files clean and scalable

- Avoid massive files

- Use feature-based modules

- Enterprise SaaS structure

- No hardcoded values

- Proper loading/error states

## UI Style

- Modern SaaS dashboard

- Clean spacing

- Minimal design

- Dark/light ready

- Fast UX

## Project Goal

Build an enterprise influencer marketing operations platform for:

- clients

- campaigns

- influencers

- deliverables

- finance

- analytics

- approvals

- workflows
