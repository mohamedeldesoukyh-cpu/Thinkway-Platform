# Performance governance artifacts

| Path | Role |
|---|---|
| `budgets.json` | Soft/hard CI budgets |
| `baseline.json` | Regression comparison floor |
| `routes/route-budgets.json` | Major routes to track |
| `monitoring/*.json` | RUM / API / SQL SLO standards |
| `reports/latest.json` | Last bundle report (CI + local) |
| `reports/latest-check.json` | Last budget check scorecard |
| `reports/latest.md` | Human-readable report |
